# PMS (Project Management System)

## Project Information
PMS is a web-based application designed to help teams manage their projects more effectively. The system allows users to create, track, and manage projects, tasks, and teams efficiently.

## Installation Instructions
To install PMS, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/tupopila365/PMS.git
   ```
2. Navigate into the project directory:
   ```bash
   cd PMS
   ```
3. Install the necessary dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```

## Features
- **User Authentication**: Secure login and registration for users.
- **Project Tracking**: Create and manage projects with deadlines.
- **Task Management**: Add, edit, and delete tasks linked to projects.
- **Team Collaboration**: Invite team members to collaborate on projects.
- **Reports**: Generate reports on project progress.

## Usage Guide
1. After starting the application, navigate to `http://localhost:3000` in your web browser.
2. Sign in or create a new account to access the dashboard.
3. Create a new project using the 'New Project' button.
4. Add tasks to your project by clicking on the project and selecting 'Add Task'.
5. Use the dashboard to monitor project progress and team activity.

Enjoy managing your projects with PMS!
